# Fund Manager Quality Analysis

This skill focuses on who runs the fund and whether the product's process appears dependable.

## Duties

- Use manager fields, fund size/scale, performance evaluation, holdings style, and risk metrics.
- Distinguish manager skill from market beta or theme tailwind.
- Check tenure stability and whether the current manager plausibly owns the track record.
- Call out scale too small/too large, manager changes, or weak disclosed evidence.

## Output Contract

Return concise internal notes:

- managerLabel
- tenureAndScale
- processEvidence
- betaVsSkill
- concerns
- missingManagerData
